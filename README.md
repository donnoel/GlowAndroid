## 🧭 Overview

Glow Daily Practice for Android is an in-development habit-building app built with Kotlin and Jetpack Compose. It explores how the Glow experience can translate to Android while keeping the interface calm, focused, and easy to use.

## 💎 Core Features

| Feature | What it does |
| --- | --- |
| **Today** | Review seeded habits and mark completion during the current session. |
| **Insights** | See derived completion, streak, and recent-activity feedback. |
| **Library** | Add suggested habits to today's list. |
| **Native interface** | Explore the Glow flow through Material 3 and Jetpack Compose. |

<details>
<summary>Feature details and controls</summary>

<a id="current-features"></a>

### Current Features

- Today view with a progress summary and interactive habit completion
- Insights view showing completion progress, streak feedback, and recent activity
- Library view for adding suggested habits to today's list
- Material 3 interface with bottom navigation across the primary flows

The current project uses in-memory sample data while the product flow and Android interface are being developed.

## 🚀 Getting Started

<a id="run-locally"></a>

### Run Locally

1. Open this repository in Android Studio.
2. Allow Gradle to sync the project dependencies.
3. Run the `app` configuration on an Android emulator or connected device running API 29 or later.

From the command line, a debug build can be generated with:

```bash
./gradlew assembleDebug
```
